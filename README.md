# NovelFlow

把脑海里的故事写成小说。AI 帮你梳理设定，分段撰写，写完一章等你点头再继续。不会写着写着忘了前面。

## 安装

打开终端，两行：

```bash
git clone https://github.com/DongxUETAFFY/NovelFlow.git
mkdir -p ~/.claude/skills && cp -r NovelFlow/skills/* ~/.claude/skills/
```

开新对话，搞定。

---

## 使用

不用记命令。像和人聊天一样说就行：

### 第一步：梳理设定

对 AI 说：

> 「我想写小说」

或者直接把你脑子里有的碎片倒出来：

> 「我想写一个赛博朋克悬疑，主角失忆了，在追查自己过去的案件」

AI 会问你几个问题——一次问完，你不用一个个回答。聊完之后 AI 给你一份结构化大纲，等你确认。你说「可以」才会生成文件。

### 第二步：开始写

大纲确认后，AI 会问你「要开始写第一章吗？」，你说：

> 「开始写」或「写吧」

AI 写第一章。写完给你看摘要，然后**停下来等你**。

### 第三步：验收

每章写完你可以：

| 你说 | 发生什么 |
|------|---------|
| 「继续」 | 写下一章 |
| 「沈鸢那段太冷淡了」 | 按你的意见重写或调整 |
| 「全部写完」 | 全自动写完剩下所有章节（每 5 章汇报进度） |
| 「review」 | 检查上一章有没有人名写错、剧情矛盾 |

想改哪章就改哪章，想停就停。下次回来 AI 记得你写到哪了。

---

## 慢一点对比

| 方式 | 适合什么时候 |
|------|------------|
| 一章一章写（默认） | 想每章都审一遍，随时调方向 |
| 全自动 | 大纲已经够细，想一口气出草稿 |

建议前 3 章一章一章来，文风稳定了再全自动。

---

## 下次回来怎么继续

打开项目目录，说：

> 「继续写小说」

AI 会自动读到上次写到哪了，从下一章开始。进度保存在 `novel/context-brief.md` 里，拷到任何电脑都能续上。

---

## 怎么工作的（如果你想了解）

```
你的想法
  ↓
novel-setup（对话梳理）
  ↓
novel/ 目录（大纲、人设、世界观）
  ↓
novel-write（分段撰写）
  ├─ 每章注入大纲+人设（不会忘设定）
  ├─ 上一章全文（保持文风）
  ├─ 金字塔压缩前文摘要（近详远略，省上下文）
  └─ 写完自动审稿（错字自己修，大矛盾问你）
```
