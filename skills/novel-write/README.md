# novel-write

Context-aware chapter generation with pyramid compression, structured self-review, and anti-decay protection. Reads the `novel/` project created by `novel-setup`.

## Install

```bash
cp -r novel-write ~/.claude/skills/
```

## Modes

| Trigger | Mode | Behavior |
|---------|------|----------|
| "start", "continue" | Interactive | One chapter → review → pause for feedback |
| "batch 5" | Batch | N chapters → review each → pause after N |
| "write all" | Full-Auto | All remaining (with pre-flight check + safety gates) |
| "review" | Review | Structured audit with fix options |
| "checkpoint" | Checkpoint | Global consistency/payoff audit without rewriting |

## Per-Chapter Flow

```
Step 0: Restore state from context-brief.md
Step 1: Assemble context (foundation + story-state + voice anchor + pyramid)
Step 2: Detect milestone chapters (from outline's Milestone column)
Step 3: Internal plan (scenes, character beats, voice match, reveals)
Step 4: Write (anti-decay rules enforced)
Step 5: Self-review (P0 auto-fix / P1 fix+log / P2 flag only)
Step 6: Update files (chapter + summary + story-state + thread-ledger + progress + context-brief)
Step 7: Pause for feedback
```

## Quality Layers

| Layer | Active |
|-------|--------|
| 7-section review checklist | Every chapter |
| P0/P1/P2 severity classification | Every chapter |
| Milestone protection (≥ avg length, ≥ 2 scenes) | Milestone chapters |
| Dynamic continuity state (`story-state.md`) | Every chapter |
| Structural health monitoring (scene density, dialogue ratio, sensory benchmark, length trend) | Ch 30+ |
| Full-auto safety gates (pre-flight, quality flood, decay signal, milestone guard, 30-chapter cap) | Full-auto mode |

## Pyramid Context Compression

| Distance | Compression | Use |
|----------|------------|-----|
| Ch C-1 | Full text | Voice Anchor — prose continuity |
| Ch C-3 to C-2 | Full summary (~300 words) | Plot continuity |
| Ch C-6 to C-4 | First 100 words | Key events |
| Ch C-10 to C-7 | First 50 words | Major beats |
| Ch 1 to C-11 | One sentence each | Narrative memory |

~9,000 tokens overhead at 100+ chapters. Importance overrides allow promoting chapters with major revelations.
