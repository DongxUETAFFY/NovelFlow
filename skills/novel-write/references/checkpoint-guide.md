# Checkpoint Guide

Use this for a lightweight global audit every 10 chapters or before long automated continuation.

## Context Budget

Do not load the whole novel. Use:
- `context-brief.md`
- `story-state.md`
- due, overdue, high-risk, or recently changed `thread-ledger.md` rows
- `progress.md` statistics and review notes
- last 10 and next 10 outline rows plus milestone rows
- summary first sentences for distant chapters
- full summaries for the last 3 chapters
- `market-brief.md` target reader, core promise, hook, and style contract

Read chapter files only when a specific contradiction cannot be resolved from summaries.

## Severity

- **Pass**: no action needed.
- **Watch**: preserve or address in the next 1-3 chapters.
- **Risk**: likely continuity, payoff, or quality problem. Pause before long automation.

## Boundary

This checkpoint diagnoses. It does not rewrite chapters. Apply only safe metadata or memory-file corrections without author approval.
