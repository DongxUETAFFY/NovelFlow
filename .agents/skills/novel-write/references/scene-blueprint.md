# Scene Blueprint

Use this only during Step 3 internal planning for the current chapter. Do not create a full-book scene database.

## Goal

Turn the current chapter outline row into 3-6 concrete scene beats so the draft becomes lived fiction instead of plot summary.

## Blueprint Format

Create this table silently:

| Scene | Function | Conflict | Turn | Emotion Shift | Thread Action |
|-------|----------|----------|------|---------------|---------------|
| 1 | setup / confrontation / reveal / aftermath | who wants what now | what changes by scene end | from X to Y | plant / advance / payoff / none |

## Rules

- Keep the blueprint under 10 bullets or one small table.
- Every scene needs a place, present-tense pressure, and an irreversible turn.
- At least one scene must render live dialogue and physical action.
- Milestone chapters need 2-3 developed scenes, not just one long summary.
- Use `thread-ledger.md` to decide whether this chapter plants, advances, pays off, reverses, or closes a thread.
- Use `reader-promise.md` or legacy `market-brief.md` only as a style and reader-promise guardrail.
- Do not output or persist the blueprint unless the user explicitly asks.
- Do not expand future chapters into scene plans. Only plan the current chapter.
